# Livestock Auction Management System

## Overview
A web-based application developed to automate livestock auction activities at Eiseb Country Traders.

## Technology Stack
- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: J2EE (Java Servlet, JSP)
- **Database**: MySQL
- **Server**: Apache Tomcat
- **IDE**: NetBeans

## Key Features
- User Authentication (Login/Logout)
- Seller Management (Add, Update, Delete, View)
- Buyer Management (Add, Update, Delete, View)
- Livestock Management (Add, Update, Delete, View)
- Auction Management (Create, Schedule, Update)
- Bid Management (Place, View, Monitor)
- Auction Results (Close, Select Winner)
- Report Generation

## Installation Steps
1. Clone the repository
2. Open in NetBeans
3. Configure MySQL database using schema.sql
4. Deploy to Apache Tomcat
5. Access at http://localhost:8080/LivestockAuctionSystem
